# 실제 브라우저 검증 · 2026-09-07

Codex 인앱 브라우저의 1280×720 화면, 4202 로컬 서버에서 일반 클릭/키보드 입력으로 확인했습니다. 게임 상태와 HP를 주입하지 않았습니다.

- 타이틀 → 전사 선택 → 홍련 출전, 전신 캐릭터와 5×5 결계 표시.
- 카드 클릭으로 금강막/붉은 부적/숨 고르기를 계획하고 세 수 펼치기: 실제 HP·기력 변화, 공격·방어 효과를 확인했습니다.
- 다음 라운드는 키보드 `4 4 5 Enter`로 입력, HP 0 패배 → 이 대전 다시 → HP 110/라운드 1 복원을 확인했습니다.
- `P` 일시정지 대화상자와 게임 입력 비활성화를 확인했습니다.
- 첫 검수에서 체력/격자/카드를 함께 보기 어려웠습니다. 압축 배치 수정 후 720px 높이에 체력·격자·계획 세 칸·전체 행동 카드가 동시에 표시됩니다.
- 수정본에서 `위 / 1 / 오른쪽 / 4 / 5 / Enter`로 방향이 다른 계획을 실행했습니다. 플레이어가 2열 2행으로 이동해 HP 110을 유지했고, 상대 부적 컷인에 실제 시전자 청우가 표시됐습니다.
- `preview.jpg`는 수정된 실제 게임에서 일반 입력으로 세 수를 고른 화면입니다. 콘솔 경고/오류 기록은 없었습니다.

모바일 실제 기기, 오디오 청취, 사람이 브라우저에서 3관문을 연속 완주한 결과는 미검증입니다. 44개 CPU 테스트와 전체 대진 종료 검사는 별도 증거이며 브라우저 완주와 혼동하지 않습니다. 전사는 정지 원화 기반으로 이동·기울기·방향·피격을 표현하며 수십 프레임 원작 애니메이션 복원은 아닙니다.
