- `npm test`: CPU 테스트 **49개 통과**. 2026-09-07 문서 갱신 시 재실행해 확인했다.
- `npm run build`: Vite 프로덕션 빌드 통과.
- `npm ci`: lockfile 기반 의존성 설치 성공, 보안 취약점 0건 보고.
- 4명의 모든 12개 대진 × 두 난이도에 대해 제한 라운드까지 AI 대 AI를 실행, 매 수 위치·생명·기력의 불변식과 최종 종료 확인.
- 25칸 화면 좌표→논리 좌표 왕복, 발밑 좌표, 보드 밖 입력 차단을 CPU로 확인.
- 240/300/480 높이 전투 화면의 축소 좌표→논리 격자 변환을 모든 25칸에서 확인.

직접 검증하는 규칙은 행 이동, 돌진 통과 방지, 같은 칸 충돌, 이동 후 공격 빗나감, 직선 부적, 방향 방어, 반격, 동시 쓰러짐, 기력 부족, 예측 큐, 원본 상태 불변성, 30라운드 종료, 3관문 전환이다.

추가된 도움말·정지 회귀 5개는 `P → H → Escape` 후 정지 및 실제 프레임 진행 차단 유지, 실행 중 연 도움말을 닫을 때 원래 상태·수의 진행 복원, 반복 `H`가 원래 상태를 임시 정지 상태로 덮어쓰지 않음, 열리지 않은 도움말 닫기가 정지 게임을 재개하지 않음, 비전투 화면에서 도움말을 닫아도 원래 화면 유지 여부를 CPU에서 확인한다. 이 중 `P → H → Escape` 후 정지 유지와 계속하기 클릭 후 실제 수·HP 진행은 부모 작업의 [브라우저 추가 점검](browser-qa.md)에서도 확인했다. 나머지 CPU 회귀까지 실제 브라우저로 확인했다는 주장은 아니다.

## 브라우저 확인

[실제 브라우저 검증 기록](browser-qa.md)에 카드/키보드 입력, HP 변화, 패배/재시작, 720px 화면 배치 수정과 재검증을 기록했다. 이 문서의 CPU 통과 기록은 브라우저 완주를 뜻하지 않는다. 실제 기기 터치·장시간 사용자 플레이·프레임레이트 프로파일·오디오 청취는 미검증이다.

## 알려진 범위

- 1인 대 AI 전용. 온라인 대전·저장·서버·계정은 없다.
- 원화 정지 자세를 전투판에서 방향/위치/피격에 맞게 배치한다. 보행·검격 수십 프레임 원화 애니메이션이나 원작 전체 카드 풀을 복원하지 않았다.
- 작은 모바일 화면에서는 배경 양옆을 줄이고 전투판 중심을 유지하며 UI 손패와 계획을 줄바꿈한다. 실제 모바일 기기 검증을 통과했다는 뜻은 아니다.
- AI는 실제 플레이어 선택을 읽지 않는 3수 예측이며, 그 예측이 항상 최적이라는 주장은 하지 않는다.
- 페이지 숨김 시 일시정지하고 계속하기로 재개한다. 도움말과 결과 대화상자는 진행을 가린다.
